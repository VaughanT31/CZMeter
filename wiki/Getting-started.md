# Getting started

*Install it, type /cz, and the meter is there.*

CZ Meter is a light damage meter built on the game's own meter data, so its totals match Blizzard's meter. It shows live bars through boss fights and Mythic+ keys in one small window.

### Install

1. **CurseForge app:** search for **CZ Meter** and click Install.
2. **By hand:** download it from [CurseForge](https://www.curseforge.com/wow/addons/czmeter) and put the `CZMeter` folder in `World of Warcraft\_retail_\Interface\AddOns`.
3. Start the game. If the game was already running, restart it rather than using `/reload`, so the new files load.

### First use

1. Type `/cz` to show or hide the meter.
2. Drag the window by its title bar to move it, and use the grip in the bottom right corner to resize it.
3. Pull something. The bars fill as you fight. See [The window](The-window.md).

There's no setup. To see a full list without being in a group, type `/cz test` for test bars.
