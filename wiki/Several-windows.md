# Several windows

*Open up to six windows and snap them together into a group.*

### A new window

Pick **New window** from the window menu, the Display page of the options, or type `/cz new`. Each new window picks the next metric, so one can show damage and another healing. You can have up to six.

### Snapping together

Drag a window close to the edge of another and it sticks to that edge, above, below or to either side. Windows stuck together are a **group**:

- Dragging any window in the group moves the whole group.
- **Lock** locks every window in the group.
- **Ungroup** in the window menu pulls the group apart again.

### Changing a whole group

In the options, tick **Editing group** at the top and every change you make goes to every window in the group at once.

### Closing a window

**Close window** in the window menu closes it. `/cz` shows or hides every window.
