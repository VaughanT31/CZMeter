# Options

*Every page of the options, and test bars to try them on.*

Open the options with `/cz options`, a left click on the minimap button, **Options** in the window menu, or Esc > Options > AddOns.

At the top, pick the **window you're editing**, and tick **Editing group** to change every window in its group at once.

### Display

- Update speed in combat
- Mouse wheel speed
- Short (1.2M) or full (1,234,567) numbers out of combat
- Clear the meter when a Mythic+ key starts, or when you enter a new dungeon or raid
- Your own row: outline it, and give it a colour of its own
- The minimap button
- Show details when hovering a row
- Create, lock, ungroup, close or delete windows

![The Display page](https://ctrlshiftzed.com/assets/img/shots/czm-options-display.webp)
*The Display page*

### Window

Skin, width, height, growing with the number of rows, scale, how many rows show, toolbar size, column headings, and the background, border and accent colours. Look settings belong to the skin, so every window wearing it changes too.

![The Window page](https://ctrlshiftzed.com/assets/img/shots/czm-options-window.webp)
*The Window page*

### Bars

Row height and gap, texture, direction, row background, class colours or one colour, brightness, opacity and the class stripe.

![The Bars page](https://ctrlshiftzed.com/assets/img/shots/czm-options-bars.webp)
*The Bars page*

### Text

Font, size, outline, colours, and which columns show.

![The Text page](https://ctrlshiftzed.com/assets/img/shots/czm-options-text.webp)
*The Text page*

### Skins

Save, delete, export and import. See [Skins](Skins.md).

### Combat log

Starting the combat log automatically, and the disk space reminder. See [Combat log and disk space](Combat-log-and-disk-space.md).

### Test bars

**Test bars** at the top of the options (or `/cz test`) fill every window with 25 made-up players, so you can try skins and see a full raid list without being in one. Turn them off the same way.
